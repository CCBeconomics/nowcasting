====================================================================
 INSTALLATION GUIDE
 GDP Growth Nowcasting Workshop -- Trinidad and Tobago (IDB, 2026)
====================================================================

Do this BEFORE the Friday installation clinic. It takes 30-60 minutes,
most of it waiting for downloads. If a step fails, do not keep trying:
write down the step and bring a screenshot to the clinic. That is what
the clinic is for.

You need: Windows 10/11, macOS 12+ or Linux; 10 GB free disk; a stable
connection (~3 GB of downloads); and permission to install programs.
On an institutional laptop, ask your IT team for that permission TODAY.


--------------------------------------------------------------------
 STEP 1. Install Anaconda (Python)
--------------------------------------------------------------------
1. Download the installer from https://www.anaconda.com/download
2. Run it with the default options ("Just Me" if you have no admin
   rights). Do NOT tick "Add Anaconda to my PATH".
3. Open "Anaconda Prompt" from the Start menu (macOS/Linux: Terminal)
   and type:

       conda --version

   It should print something like "conda 24.x". Everything below is
   typed in this same window.


--------------------------------------------------------------------
 STEP 2. Install R, Rtools and VS Code
--------------------------------------------------------------------
1. R:       https://cran.r-project.org  (latest version, default options)
2. Rtools:  https://cran.r-project.org/bin/windows/Rtools/
            Windows only. Pick the version that matches your R
            (R 4.5.x -> Rtools45). macOS: run  xcode-select --install
3. VS Code: https://code.visualstudio.com
            Then, in VS Code, open Extensions (Ctrl+Shift+X) and install:
            "Python" (Microsoft), "Jupyter" (Microsoft), "R" (REditorSupport).


--------------------------------------------------------------------
 STEP 3. Download the course material
--------------------------------------------------------------------
1. Go to https://github.com/CCBeconomics/nowcasting
2. Green "Code" button -> "Download ZIP". Unzip it somewhere simple,
   e.g. Documents\nowcasting.
3. The workshop is the folder  tto/ . Everything below refers to it.

   (If you use git:  git clone https://github.com/CCBeconomics/nowcasting.git
    and later  git pull  to get updates.)


--------------------------------------------------------------------
 STEP 4. Create the two Python environments
--------------------------------------------------------------------
In Anaconda Prompt, go to the install folder (adjust the path):

    cd Documents\nowcasting\tto\install

Then run these lines, one at a time:

    conda env create -f environment.yml
    conda activate nwcst
    python -m ipykernel install --user --name nwcst

    conda env create -f environment-geo.yml
    conda activate geo
    python -m ipykernel install --user --name geo

Each "conda env create" takes 10-20 minutes and may sit on
"Solving environment" for a long time. That is normal.

  - Stuck for more than 20 minutes? Press Ctrl+C, then:
        conda install -n base mamba
        mamba env create -f environment.yml
  - Still failing? Use manual_install.txt (same folder): the same
    packages in several smaller commands, so you can see which one
    breaks. Bring that message to the clinic.

The "geo" environment is only for Activity 3 (nighttime lights).


--------------------------------------------------------------------
 STEP 5. Check that everything works
--------------------------------------------------------------------
Open the  tto/  folder in VS Code (File -> Open Folder).

PYTHON: open  install/act0_env_check.ipynb
  - Top right, "Select Kernel" -> nwcst. Run Part 1.
    You should see "LinearRegression OK" and "LSTM OK".
  - Switch the kernel to geo, paste your NASA token (Step 6) and run
    Part 2. You should see a map and "Geo environment OK".

R: open  install/act0_env_check_R.Rmd  and run the chunks in order
   (Ctrl+Enter). The first run installs the packages (10-15 minutes).
   The last chunk should print OK on every line.


--------------------------------------------------------------------
 STEP 6. Free accounts for data downloads
--------------------------------------------------------------------
These are personal. Do not share them or paste them into a file you
send to anyone.

FRED (Activity 2)
  1. Create an account at https://fredaccount.stlouisfed.org/apikeys
  2. Request an API key (32 characters, arrives instantly).
  3. Paste it into FRED_API_KEY = "" at the top of activity/act2_scraping.ipynb.

NASA LAADS (Activity 0 Part 2 and Activity 3)
  1. Register at https://ladsweb.modaps.eosdis.nasa.gov/
  2. Profile -> EULAs -> accept "Meris EULA" and "Sentinel-3 EULA".
  3. Profile -> Applications -> Authorized Apps: find "LAADS Web"
     (you may need "Approve More Applications" and search for it).
  4. My Account -> Generate Token. Paste it into
     NASA_TOKEN = "" in activity/config.py.
  Tokens expire after 60 days. A download that fails with an
  authorization error almost always means: generate a new token.


--------------------------------------------------------------------
 COMMON PROBLEMS
--------------------------------------------------------------------
"conda is not recognized" (Windows)
    You are in the wrong window. Use Anaconda Prompt, not cmd or
    PowerShell.

Proxy / SSL errors during the install
    Ask IT for the proxy settings, or install over a phone hotspot.

Error importing pmdarima or torch
    Delete the environment and create it again:
        conda deactivate
        conda env remove -n nwcst
        conda env create -f environment.yml

The kernel "nwcst" or "geo" does not appear in VS Code
    Run the "python -m ipykernel install ..." line from Step 4 again,
    then restart VS Code.

R says "Rtools NOT found"
    Install Rtools (Step 2), restart VS Code, run the chunk again.
